# 개인별 진단처방기록부 개선 시안

수학팀 박소영 과장이 보낸 Google Slides `진단처방기록부 개선 영상`(2026.11.18, 1쪽 대본 + 장표 6쪽, 회장님 보고용)으로 만든 설명 영상이에요. 내레이션은 1쪽 대본(팀장님이 같은 날 오전에 고친 판)을 글자 그대로 읽어요. 요청은 세 가지였어요: 대본은 1쪽, **새로 구성된 요소를 설명할 때마다 줌인**, 여자 목소리.

- **ver2(2026.11.18)**: p. 6 오답 보기 화면의 오답사례 · 학습목표 · 학교진도 줄에 하나씩 그려졌다 사라지던 상자를 세 줄을 한 번에 두르는 상자 하나로("오답 사례" 에서 그려져 쪽 끝까지 남아요). 2분 14.5초 ~ 2분 21.6초만 다시 렌더
- **ver3(2026.11.18)**: 두 번째 검토 7항목. 발음: 진단평가 → 진단평까(l1_1), 강점 → 강쩜(1:34 의 l4_6 과 같은 말이 있는 l2_2 · l4_11 도), 읽는 형태(`SAY`)로 다시 읽혀 wav2vec2 로 된소리를 확인해 `TAKE` 로 고정. 화면: 선생님 아이콘을 칠판을 지시봉으로 가리키는 모습으로, 칩 글자를 글자 모양 기준으로 가운데(`chip`), p. 5 쪽 전체의 ①~⑤ 번호는 렌즈가 줌인하면 사라지고, 원그래프 동그라미는 고리 안(75% · 99/132)으로 줄여 전체 평균 88% 를 가리지 않게, p. 7 "위에서 · 아래에서" 상자는 앞 상자가 사라진 뒤에 다음 상자가 그려지게(`focusAt` 의 seq). 길이가 바뀌어 전체 렌더
- **ver4(2026.11.18)**: p. 6 오답 보기 화면에서 문항 상자가 다 그려지기 전에 아래 세 줄 상자가 겹쳐 그려지던 것을, 문항 상자를 "문항과" 에 맞춰 다 그린 뒤 지우고 나서 세 줄 상자를 그리게(`focusAt` 의 seq). 2분 14초 ~ 2분 21.5초만 다시 렌더
- **ver5(2026.11.20)**: 덱 1쪽 `수정내용` 11항목 + 2쪽 고친 대본(바뀐 10문장만 새로 읽힘, 나머지는 확인한 테이크 그대로, `PACE = 6.71`). p. 5 번호 원은 처음엔 없고 그 항목 차례에만 보이게, 원그래프는 동그라미 대신 75 %까지 파랗게 차오르게(`donutFill`), "구간과" 에 보통 칸 상자, 학습출발점 · G25 는 커졌다 작아지게(`pulse`), QR 은 별도 쪽 없이 같은 쪽에서 렌즈가 QR → 오른쪽에 놓인 오답 보기 화면으로 이동. p. 6 그래프는 빨간 동그라미 대신 아래 → 위 영역 깜빡임(`blink`), 학습출발점 점 · 점선 · 16주 · 끝점이 커졌다 작아지게, 예상 진도 · 처방 프로그램 번호 ③, 세트 번호는 동그라미 대신 G25 위 말풍선 "G361"(`callout`). 감사합니다는 p. 8 별도 쪽. 기존 리포트 쪽은 "총평" 문장에 맞춰 총평 상자로 렌즈 이동. 대본 "어떤 학습 을" 은 "학습을" 로 씀. 2페이지 상단 그래프 이미지는 바뀔 예정(박소영): 오면 `assets/new_p2.png` 를 바꾸고 `SC.p2` 의 그래프 픽셀 좌표를 다시 재요
- **모눈종이 워크북 한 장**: 장면마다 한 쪽(p. 1 ~ p. 8). 쪽이 바뀔 때만 종이가 옆으로 넘어가요(휙 소리와 같은 때). 그림 · 펜 표시는 내레이션 단어에 맞춰 나타나요(`Wc(문장, 단어)`)
- **줌 렌즈**(`lens`, 이 영상에서 새로 만듦): 기록부 쪽을 틀 안에 놓고, 설명하는 부분으로 카메라가 1.1초 동안 미끄러지듯 다가가요(`camAt`, 확대는 로그 비율로 부드럽게, 그림이 흐려지지 않게 1.45배까지). 그 부분 말고는 흐려지고 빨간 손그림 상자가 둘러져요(`focusAt`). 틀 아래에는 장표의 그 항목 번호 · 이름 · 설명(`caption`), 오른쪽 아래에는 지금 보는 곳을 빨간 칸으로 보여 주는 작은 지도(`miniMap`)가 있어요. 템플릿 규칙은 "카메라 줌 없음" 이지만 이번 요청이 줌인이라 렌즈 안에서만 움직여요(쪽 자체는 그대로)
- **기록부 그림**: 장표 pptx 에 들어 있던 원본 그림(1450×2048)을 `assets/` 에 그대로 두었어요: `old_p1.jpg` · `old_p2.jpg`(기존 1 · 2페이지), `new_p1.png` · `new_p2.png`(개선 시안 1 · 2페이지), `wrong_view.png`(QR 로 여는 영역별 오답 보기 화면)
- 색: `content.js` 의 `colors`(기준 `../.claude/skills/graph-paper-video/reference/colors.md`). 레드 = 섹션 태그 · 항목 번호 · 펜 · 렌즈 상자, 네이비 = "보완 필요" 동그라미(모르는 것), 잉크 = "이렇게 바꿉니다" 어두운 카드
- 글꼴: 본문 Noto Sans KR(라틴 글자는 Avenir Next), 손글씨 Gaegu Bold — `fonts/`(OFL)
- 길이 3분 16초(195.6초), 말 빠르기 약 6.7자/초, 1920×1080, 30fps. 배경음악 없음(내레이션 + 쪽 넘김 휙 소리, 시작과 끝의 차임). 화면 자막 없음(`subtitles.srt` 따로)

## 대본 · 음성 · 시각표

- 대본: `tools/script.py`(28문장, 슬라이드 1쪽 그대로). 읽는 형태만 바꾼 곳(`SAY`): 1페이지 → 일 페이지, 2페이지 → 이 페이지, 4자리 → 네 자리, QR코드 → 큐알 코드. 긴 문장은 `BREATH` 의 낱말 뒤에 쉼표를 넣어 읽혀요(화면 · 자막은 원문)
- 목소리: `../jei-math-difference-ko` · `../ai-learning-platform-v3-ko` 와 같은 한국어 목소리(`~/Desktop/ai플랫폼학습용.mp3`, 약 176 Hz. `audio/voice_ref.wav` + `audio/voice_ref.txt` 를 복제 레퍼런스로). 처음엔 여자 목소리로 적었지만 남자 목소리로 들려요(2026.11.24, `../learning-plan-graph` ver1 에서 확인). 요청대로 여자 목소리로 바꾸려면 `../learning-plan-graph` 처럼 어댑티브진단 여자 목소리(`../jei-ai-vision-ko/audio/voice_ref.*`, 약 229 Hz)로 다시 읽혀요. DGX Qwen3-TTS(`http://192.168.51.8:8095`, `/v1/tts/clone`)가 문장마다 3번 읽고, whisper large-v3-turbo 로 받아써서 골라요. 읽는 형태 뒤에 "감사합니다." 를 붙여 읽히고 그 앞 쉼에서 잘라요(줄 끝이 잘리지 않게)
- 받아쓰기 경고 정리: whisper 는 l1_2 의 "시안" 을 "시한" 으로, l4_4 · l4_6 의 "보완" 을 16번 모두 "보안" 으로 적었지만 wav2vec2 음소로 확인하면 "ɕ j a n" · "p u w a n" 이라 대본대로 읽었어요. 그 테이크와 높이가 고른 l4_8 테이크 2(170Hz, 자동 선택은 149Hz)를 `TAKE` 로 고정했어요
- 첫 문장은 1.3초에 시작하고(0.25초에 차임), 문장 사이 0.6초, 쪽 사이 1.8초, 마지막 문장 뒤에 같은 차임

```bash
npm install
uv run --with numpy --with mlx-whisper python tools/make_audio.py tts   # → timeline.js · audio/mix.wav · subtitles.srt
node tools/snap.mjs out/snaps --ends                                     # 쪽마다 다 그려진 화면
node render.mjs --workers 3                                              # → out/diagnosis_record_improvement.mp4
```

- 최종 믹스는 `audio/mix.flac` 으로 보관해요. 다시 렌더할 때는 `node_modules/ffmpeg-static/ffmpeg -i audio/mix.flac audio/mix.wav`
