# GEO 모니터링 콘솔 (경영진 설명, 1분)

GEO 모니터링 콘솔(geo.esls.io)이 무엇이고 왜 만들었는지를 경영진에게 1분 안에 보여 주는 영상이에요. 목적, 개발할 때 신경 쓴 부분, 기대효과를 담았어요.

- 그림 방식: 앱 홍보 **모션그래픽**이에요(사용자가 준 참고 영상: 지그재그 SNS 광고, 링글 쇼츠, 앱 홍보 재생목록). 화면 가득한 브랜드 레드 그라데이션과 흰 배경이 번갈아 나오고, 큰 글자가 내레이션 단어에 맞춰 튀어나와요. 채팅창 타이핑, 날아드는 카드, 스포트라이트, 돋보기, 마우스 클릭, 스위치가 켜지는 움직임이 들어가요. 장면은 원형으로 넘어가요(휙 소리)
  - 1차본(모눈종이 워크북)은 "모눈종이 컨셉은 아니야, 흥미도 중요해"라는 의견으로 바꿨어요
- 이야기: 질문을 먼저 던지고 답해요("재능교육은 나올까요?" → 지금까지는 → 콘솔 → … "믿을 수 있을까요?" → "기준이 바뀌면요?" → 기대효과)
- **대본에는 리포트 결과를 넣지 않아요**: 실제 회차 수치, 순위, 경쟁사에 밀리는 내용은 내레이션과 큰 글자에 없어요(요청: 긍정적인 부분 강조). 앱 화면은 캡처 그대로 보여 줘요(사내 보고용이라 가리지 않아도 된다는 요청): 01 질문군, 02 리포트 AI 요약, 03 리포트 질문별 결과, 06 지표 설정
  - 화면의 다른 사실은 브리프에서 온 것만 써요: 세 AI, 정해진 주기마다 자동 수집(화면 예시: 주기 1일), 11시 구글챗 알림, 팀별 권한, 질문군 이름 두 가지, 지표 계산식(06 화면 문구 그대로), 근거 질문 칩(q13 ChatGPT 등)
  - 왼쪽 메뉴(아래쪽에 직원 이메일)는 잘라내요. `09-members.png`(직원 이메일), `10-notify.png`(웹훅 주소)는 `.gitignore` 에 있어요
- "매일"이라고 하지 않아요: 수집 주기는 질문군마다 정하는 설정이라(2주에 한 번일 수도 있어요) 대본은 "정해진 주기마다"예요
- 글자는 적게: 한 장면에 핵심 단어 한두 개만 크게 보여 줘요(요청)
- 내레이션: 해요체 11문장. 참고 재생목록의 앱 가이드 내레이션 목소리(`audio/voice_ref_b.wav`, 배경음악을 demucs로 걷어낸 17초)를 DGX Qwen3-TTS가 복제해 읽어요(`tools/script.py` 의 `VOICE`). 처음 쓰던 `../ai-learning-platform-v3-ko` 목소리(`audio/voice_ref.wav`)는 `VOICE=voice_ref` 로 다시 뽑을 수 있어요. 성우의 실제 목소리를 복제한 것이라 내부 검토용이에요
- 배경음: 앱 홍보 영상 같은 신나는 팝을 `tools/make_audio.py` 의 `music()` 이 직접 합성해요(116 BPM). 1차본보다 크게 깔았어요(최고 0.55, 말할 때 35%만 줄임). 끄려면 `tools/script.py` 의 `MUSIC = False`
- 화면 글자는 가운뎃점(·) 대신 쉼표를 써요
- 색: `content.js` 의 `colors`. 레드 = 브랜드, 배경, 강조 상자, ChatGPT. 블루 = Gemini, 민트 = Claude. 네이비 = "지금까지의 방식" 장면 하나
- 강조 상자: 단어 뒤로 상자가 쓸려 들어오고, 상자가 지나간 부분만 글자 색이 바뀌어요(한 번에 바꾸면 깜빡여 보였어요). 한글은 '가'의 실제 높이로 가운데를 맞춰요
- 1920×1080, 30fps, 1분 이내(59.8초)

## 대본, 음성, 시각표

- `tools/script.py`: 대본(`_SCRIPT`), 장면 목록, 읽는 형태(GEO → 지이오), 숨 쉴 쉼표(`BREATH`), 질문 문장(`QUESTIONS`, 앞에 올라가는 두 음), 간격
- 문장 끝 잘림: TTS 서버는 말소리가 끝나는 순간 출력을 끊어서 마지막 음절이 툭 끊겨 들려요(광고 내레이션처럼 끝을 세게 말하는 목소리에서 특히). 그래서 `make_audio.py` 가 문장마다 뒤에 "감사합니다."(`TAIL_TEXT`)를 붙여 읽히고, 두 문장 사이 쉼에서 잘라 내요. 그러면 문장 끝이 자연스럽게 떨어지고 0.2초쯤 여유가 남아요. 그래도 소리 도중에 끝나는 녹음은 고르지 않아요
- 남는 `!` 경고는 받아쓰기 표기 차이예요(세 ↔ 새)

```bash
npm install
uv run --with numpy --with mlx-whisper python tools/make_audio.py tts                          # → timeline.js, audio/mix.wav, subtitles.srt
VOICE=voice_ref uv run --with numpy --with mlx-whisper python tools/make_audio.py tts          # 처음 목소리로 (같은 파일을 덮어써요)
```

## 고치기, 렌더링

- 장면: `index.html` 의 `SC.title` ~ `SC.end` (배경은 `BGOF`, 원형 전환 시작점은 `ORIGIN`). 화면 문구와 색: `content.js` (영상 편집기에서도 수정 가능)
- 미리보기: `index.html` (재생 막대), `index.html?t=20` (그 시각)

```bash
node tools/snap.mjs out/snaps --ends            # 장면마다 끝나기 직전 정지 화면 + 못 찾은 큐 단어
node render.mjs --workers 3                      # out/geo_monitor_ko.mp4 (GPU)
node render.mjs --workers 3 --only 33-42         # 고친 구간(초)만 다시 그려요
```
