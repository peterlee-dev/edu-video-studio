## 대본 · 음성 · 시각표

- `tools/script.py`: 대본(`_SCRIPT`), 장면 목록(`SCENES`), 같은 종이 장면(`CONT`), 읽는 형태(`SAY`, `BREATH`), 테이크 고정(`TAKE`), 간격
  - 쓰는 형태는 PDF 대본 그대로예요. PDF 추출에 섞인 띄어쓰기만 바로잡았어요("제공하고 ," → "제공하고,", "결손으 로" → "결손으로", "서비스 로" → "서비스로", "플랫폼 입니다" → "플랫폼입니다", "**‘…’**" → "‘…’")
  - 검토(2026.11.04)로 고친 문장: l10_3 에 "미학습" 을 더해 네 가지로 읽고("완전히 이해함, 보완 필요, 결손, 미학습으로 구분됩니다."), l10_4 "이 중 결손으로 확인된 학습목표는 가장 먼저 보완합니다." 를 새로 넣었어요(뒤 문장은 l10_5 ~ l10_7 로 밀림)
  - 검토(2026.11.05, `어댑티브진단&AI플랫폼 소개_ 영상 수정 요청.pdf`)로 PDF 8쪽 대본 l8_3 ~ l8_6 을 시트 문장으로 바꿨어요(콘텐츠를 학습목표별로 미리 생성해 검토된 DB에 쌓고, DB에서 POD 학습지로 출력. l8_6 "검증한 후" → "검증한 뒤"). l8_4 는 pod 장면으로 옮겼어요
  - PDF 6쪽의 "그 위의 AI 에이전트 계층에서는 …, 최상위 서비스 계층에서는 …" 한 문장은 두 장면에 걸쳐 있어서 쉼표에서 `l6_3` / `l6_4` 로 나눴어요(글자는 그대로)
  - 읽는 형태: "Knowledge" 는 영어 그대로, Map 은 "맵"(검토: "놀리지 매프" 처럼 끝에 모음이 붙지 않게), JEI → 제이이아이, JEI-SLI → 제이이아이 에스엘아이, JEI Math Universe → 제이이아이 매스 유니버스, POD → 피오디, DB → 디비, LLM Wiki → 엘엘엠 위키, CCSS → 씨씨에스에스, 50년간 → 오십 년간, 7개 → 일곱 개. 따옴표는 읽지 않고 가운뎃점(·)은 띄어 읽어요
  - 쉼: `BREATH` 의 단어 뒤에만 읽는 형태에서 쉼표를 넣어 구절 사이에서 숨을 쉬게 해요. 말 빠르기는 바꾸지 않아요(`TEMPO = 1`)
- 목소리: `../ai-learning-platform-v3-ko` 와 같은 목소리예요(`audio/voice_ref.wav` + `audio/voice_ref.txt` 를 복제 레퍼런스로). DGX Qwen3-TTS(`http://192.168.51.8:8095`, `/v1/tts/clone`)가 문장마다 읽어요
- `tools/make_audio.py tts`: `../geo-monitor-ko` 처럼 읽는 형태 뒤에 "감사합니다." 를 붙여 읽히고, 그 앞 쉼에서 잘라요(DGX TTS 가 줄 끝을 잘라먹어서). 문장마다 3번(다시 읽힌 문장은 8~12번) 읽히고, whisper large-v3-turbo(mlx-whisper, 이 맥)로 받아써서 골라요. 끝 무음이 0.2초 안 되는 테이크는 잘린 것으로 쳐요. 고른 57개 테이크 모두 끝 무음 0.20초 이상이에요
  - whisper 는 잘못 읽은 발음을 놓쳐서, 이름이 든 문장은 테이크마다 wav2vec2 음소(`facebook/wav2vec2-lv-60-espeak-cv-ft`)와 이름 부분만 자른 whisper 로 한 번 더 보고 `TAKE` 에 고정했어요: JEI 는 "제이 이아이"(제아이 아님), JEI-SLI 는 에셀아이, POD 는 피오디(푸디 · 피디 아님), LLM 은 엘엘엠, Knowledge 는 첫 모음 /a/(놀 아님), 맵은 p 뒤 모음 없음
  - whisper 는 목소리 높이가 갑자기 낮아진 테이크도 그냥 통과시켜요(검토 2026.11.04: l4_2 가 중간값 124Hz, 다른 문장은 160~190Hz). 다시 읽힌 문장은 테이크마다 2초 구간별 높이(F0)를 재서 고르게 유지되는 것을 `TAKE` 에 고정했어요(l4_2 → 4번). 새로 쓴 l8_3 ~ l8_5 도 같은 방법으로 골라 고정했어요(POD 가 피디 · 피우디로 읽힌 테이크, 끝에서 122Hz 로 떨어진 l8_5 테이크는 뺌). 새 문장 때문에 말 빠르기 중간값이 바뀌어 자동 선택이 달라진 l6_1 은 이전 테이크로 고정했어요
  - 남은 `!` 경고 6개는 모두 받아쓰기 표기 차이예요(MASS/MES Universe ↔ 매스 유니버스, 3개 ↔ 세 개, 위에 ↔ 위의, LLM 위키 ↔ 엘엘엠 위키, 제시도 ↔ 재시도, JISLI ↔ 제이이아이 에스엘아이)
- 첫 문장은 1.3초에 시작하고(0.25초에 차임), 문장 사이 0.6초, 쪽 사이 1.8초. 한 문장을 쉼표에서 나눈 l6_3 → l6_4 는 0.35초만 쉬어요(`JOIN`). 마지막 문장 0.45초 뒤에 같은 차임이 울려요(`DING_END`, 대본에 끝인사가 없어서)
