# 화면 언어: 모눈종이 워크북

영상 전체가 **모눈종이 워크북 한 장**이에요. 장면마다 한 쪽(p. 1, p. 2 …)이고, 선생님이 그 쪽을 펜으로 채점하듯 설명이 진행돼요. 이 문서의 함수 이름은 모두 `template/index.html` 에 있어요.

## 쪽 배치 (1920×1080, 30 fps)

| 자리 | 값 | 함수 |
|---|---|---|
| 모눈 | 40 px 칸, 200 px 마다 진한 선 | `paper(cam)` |
| 왼쪽 여백선 | x = 150 (빨간 연한 세로선) | `pageFurniture(i)` |
| 쪽 번호 | 오른쪽 위 (1800, 92), 손글씨 `p. 3` | `pageFurniture(i)` |
| 섹션 태그 | (210, 92), 레드 칩, 대문자 + 자간 (`01  ·  BACKGROUND`) | `header()` |
| 제목 | (210, 160), 54 px 700 | `header()` |
| 부제 | (210, 228), 26 px 슬레이트 | `subline()` |
| 본문 영역 | x 210 ~ 1800, y 280 ~ 920 | — |
| 맺음 띠 | 아래쪽 어두운 띠 한 줄 | `bar()` |

- 내용의 왼쪽 끝은 x = 210(여백선 오른쪽)에 맞춰요. 오른쪽 끝은 1800
- 제목 쪽(첫 장)만 섹션 태그 대신 kicker 칩 + 92 px 큰 제목 세 줄(첫 줄 레드 + 형광펜), 손글씨 팀 이름
- 마지막 쪽은 체크 목록 + 손글씨 `Thank you` + 빨간 펜 밑줄
- 글꼴: 본문 Avenir Next, 손글씨 Noteworthy (macOS 시스템 글꼴). 한글은 Apple SD Gothic Neo / Noto Sans KR 로 대신 그려져요. 다른 OS에서 렌더하면 글꼴이 바뀌니 macOS에서 렌더해요

## 선생님 펜 (무엇을 언제)

| 표시 | 함수 | 쓰는 때 |
|---|---|---|
| 동그라미 | `penCircle` | 핵심 숫자 · 답 · 고른 항목을 짚을 때 |
| 체크 ✓ | `check` (레드) | 맞음 · 완료 · 목록 항목 |
| 가위표 ✗ | `crossMark` (네이비) | 틀림 · 빼는 것 |
| 밑줄 | `pen` | 핵심 구절을 읽는 순간 |
| 화살표 · 곡선 화살표 | `penArrow`, `penCurve` | 흐름 · 변화 · 연결 |
| 손그림 상자 | `hbox` | 묶음 · 정답 칸 |
| 형광펜 | `hiLite` (블러시, 곱하기) | 제목의 핵심 단어, 맺음 문장 |
| 포스트잇 | `sticky` (라이트 박스) | 덧붙이는 메모 · 기준 |
| 도장 | `stamp` | 판정 한마디 (UNDERSTOOD, MASTERY, REVIEWED) |
| 손글씨 메모 | `text(..., { fam: HAND })` | 짧은 설명 · 강조 한마디 |

펜 표시는 모두 `k`(0 → 1)만큼 그려지는 획이라, `p(t, 시작, 길이)` 로 그 단어가 읽히는 순간에 그어져요. `nz()` 고정 흔들림이라 프레임마다 떨리지 않아요.

## 움직임 규칙

- **장면이 바뀔 때만 종이가 옆으로 넘어가요**(0.8초, 휙 소리와 같은 때). 읽는 동안 카메라는 움직이지 않아요. 줌 · 흔들기 · 기울이기 없음
- 요소는 들어올 때만 움직이고(`enter`: 살짝 올라오며 나타남, `pop` 은 튀어나옴) 그다음엔 제자리에 있어요
- 같은 종이에서 일부만 바뀌는 쪽은 `CONT`(쪽 넘김 · 휙 소리 없이 바뀌는 부분만 겹쳐 바뀜, 남는 그림은 `SHARED`)
- **모든 시각은 내레이션에 묶어요**: 그 단어가 읽히는 때 `Wc('l2_2', 'burden')`, 문장의 비율 `st('l2_2', .5)`, 문장 끝 `en('l2_2')`, 쪽 머리 `H0('problem')`. 초를 숫자로 박지 않아요(대본이 바뀌면 같이 움직이게). 단어를 못 찾으면 `snap.mjs` 가 알려 줘요 — 철자를 여러 개 주세요: `Wc(id, ['91', 'ninetyone', 'ninety'])`
- `draw(t)` 는 시간의 순수 함수: 상태를 쌓지 않고 t 만으로 그려요(병렬 렌더 · 부분 렌더가 이걸로 가능해요)
- 영상 끝 1.2초는 종이색으로 흐려져요
- 자막은 화면에 넣지 않아요(필요하면 `subtitles.srt` 를 따로 써요)

## 검토에서 지적받았던 것 (그리기 전에 확인)

- **용어 · 철자 통일**: 제목과 본문, 앞뒤 쪽에서 같은 말을 같은 철자로 (Roadmap / Road Map, Repeated / Repetitive practice 가 섞였다가 고침). 대본에서 더 자주 쓰는 표기로 맞춰요
- **움직임에 딸린 표시는 같이 사라져요**: 토끼가 뛰어 나가면 그 옆 손글씨 `−3` 도 함께 흐려져야 해요. 남아 있으면 오류로 보여요
- **표의 구분선**: 머리 칸 바탕을 먼저 칠하고 격자 선을 그 위에 그려요(바탕이 선을 덮으면 x · y 구분선이 사라져요)
- **흰 바탕 깔기**: 칩 · 원 · 라벨 · 말풍선은 색을 칠하기 전에 흰색을 먼저 깔아 모눈과 선이 비치지 않게 (`chip`, `num`, `bubble` 이 그렇게 해요)
- 형광펜은 글자를 가리지 않게 곱하기로 (`hiLite`)
- 글자가 상자를 넘지 않게 `maxW` 를 줘요(넘치면 글자 크기를 줄여 맞춰요)
- 장표 · 대본에 없는 숫자 · 일정 · 주장은 화면에 넣지 않아요. 대본에서 빠진 내용은 화면에서도 빼요
