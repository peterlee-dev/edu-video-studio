# 목소리 기준 녹음 (voice clone reference)

`tts` 모드에서 Qwen3-TTS 가 복제하는 목소리예요. 폴더마다 `voice_ref.wav`(기준 녹음) + `voice_ref.txt`(그 녹음에서 말한 문장 그대로). 새 영상은 `scripts/new_video.sh <폴더> --voice <id>` 로 그 영상의 `audio/` 에 복사돼요.

| id | 언어 | 들리는 성별 | 음 높이(중간값) | 길이 | 원 녹음 | 이 목소리의 말 빠르기(PACE) |
|---|---|---|---|---|---|---|
| `en-female` | 영어 | 여자 | 약 223 Hz | 14.8초 | 어댑티브 진단 내레이션 녹음 14.1–28.95초 | 약 15.0–15.4 자/초 |
| `en-male` | 영어 | 남자 | 약 122 Hz | 29.4초 | JEI Math D–I 개선 내레이션 녹음 처음 29초 | (첫 실행에서 출력되는 값) |
| `ko-female` | 한국어 | 여자 | 약 217 Hz | 8.4초 | `어댑티브학습용.mp3` | 약 5.64 자/초 |
| `ko-male` | 한국어 | 남자로 들림 | 약 171 Hz | 7.9초 | `ai플랫폼학습용.mp3` | 약 6.77 자/초 |

- **성별은 문서 표기가 아니라 음 높이로 확인해요.** `ko-male` 녹음은 처음에 여자 목소리로 적혀 있었지만 실제로는 남자로 들려서, 그걸로 만든 영상을 "왜 남자 목소리야?" 하고 다시 만든 적이 있어요. 여자 목소리는 대략 210 Hz 이상이에요. 새 녹음을 더할 때는 재고 적어요: `uv run --with praat-parselmouth python -c "import parselmouth as p, numpy as n; f=p.Sound('voice_ref.wav').to_pitch(pitch_floor=75, pitch_ceiling=400).selected_array['frequency']; print(n.median(f[f>0]))"`
- **영어 녹음으로 한국어를 읽히지 않아요**(그 반대도). 다른 언어 기준 녹음을 복제하면 억양이 따라와서("재능스스로수학" → "제닌스스 로스왁") 쓸 수 없었어요. 한국어 영상은 `ko-*`, 영어 영상은 `en-*`
- `en-female` 은 녹음 끝의 쉼까지 포함해 28.95초에서 잘랐어요. 28.7초(마지막 단어 "questions" 의 s 에서 바로 끝)로 자르면 복제 목소리가 문장 끝 단어를 자주 삼켜요(growth → "gro"). **기준 녹음은 문장이 끝나고 0.2초쯤 쉼이 있는 곳에서 잘라요**
- 기준 녹음을 바꾸면 그 영상의 모든 문장을 다시 읽어요(`audio/tts_cache` 의 키에 기준 녹음이 들어가요)
- 말 빠르기(PACE)는 테이크를 고를 때 기준이 되는 값이에요(`tools/script.py` 의 `PACE`). 같은 목소리로 같은 느낌을 내려면 위 값으로 고정해도 돼요
- 사내 영상 내레이션 녹음에서 자른 것이라 사내 영상용으로만 써요. 외부 성우 · 다른 회사 영상에서 딴 목소리는 넣지 않아요(내부 검토용으로 쓴 적은 있지만 여기엔 없어요)

## 새 목소리 더하기

1. 잡음 · 배경음악 없는 녹음에서 문장 단위로 8~30초를 골라요(배경음악이 있으면 demucs 로 걷어내요). 끝은 쉼 안에서 잘라요
2. `voices/<언어>-<이름>/voice_ref.wav` 와, 그 구간에서 말한 문장을 글자 그대로 `voice_ref.txt` 에
   - 녹음 전체를 받아써서 구간을 고르려면: 영상 폴더에 `audio/narration.mp3` 를 두고 `make_audio.py ref A B` (A–B 초를 자르고 받아쓴 문장을 함께 써 줘요)
3. 음 높이를 재서 위 표에 한 줄 더해요. 세 문장쯤 `tts` 로 읽혀 들어 보고, `tools/voice_check.py pitch` 로 문장마다 높이가 고른지 봐요
