## 대본 · 음성 · 시각표

- 대본: `tools/script.py`(36문장). 읽는 형태만 바꾼 곳(`SAY`): D등급 → 디등급, C등급 → 씨등급, 6 · 19 · 25세트 → 여섯 · 열아홉 · 스물다섯 세트, 25주 → 이십오 주, 26주차 → 이십육 주차, 평가 → 평까, 교점 → 교쩜, 출발점 → 출발쩜. 다음 줄로 이어지는 조각(l0_5 "…실시한 후", l1_7 "…학습하고")은 읽는 형태 끝에 쉼표(`READ`), 긴 문장은 `BREATH` 의 낱말 뒤에 쉼표
- 목소리: 한국어 여자 목소리(`audio/voice_ref.wav` + `voice_ref.txt` = `../jei-ai-vision-ko` · `../adaptive-diagnosis-v2-ko`, `~/Desktop/어댑티브학습용.mp3` 8.4초, 약 229 Hz). DGX Qwen3-TTS(`/v1/tts/clone`)가 문장마다 3번(다시 읽은 문장은 8번) 읽고 whisper large-v3-turbo 로 받아써서 골라요. 말 빠르기 기준 `PACE = 5.64`(같은 목소리의 `../jei-ai-vision-ko` 와 같게)
- 받아쓰기 경고 정리(`TAKE`): l2_1 "실선은" 은 whisper 가 8번 모두 "실서는" 으로 적었고, wav2vec2 음소로 보면 테이크 7 만 ㄹ 이 들려요("s i r s ɔ n", 나머지는 시선은 처럼). l4_3 "몇 주차에" 는 whisper 가 "주차의" 로 적지만 음소로는 테이크 2 가 "tʃ a j e"(주차에). 문장별 음 높이 225~275 Hz(l2_1 만 308 Hz: 이 문장은 8개 테이크가 모두 높게 읽혀요)
- 첫 문장은 1.3초에 시작하고(0.25초에 차임), 문장 사이 0.6초, 섹션 사이 1.5초, 마지막 문장 뒤에 같은 차임

```bash
npm install
uv run --with numpy --with mlx-whisper python tools/make_audio.py tts   # → timeline.js · audio/mix.wav · subtitles.srt
node tools/snap.mjs out/snaps --ends                                     # 쪽마다 다 그려진 화면

```
