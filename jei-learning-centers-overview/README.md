## 음성 · 시각표 만들기

- 대본: `tools/script.py`. JEI 는 모두 "J-E-I" 로 읽혀요. 숫자는 말로 적었어요(1992 → "nineteen ninety-two", June 2026 → "June twenty twenty-six", 54 → "fifty-four", 130 to 180 dollars → "one hundred thirty to one hundred eighty dollars" 등)
- 목소리: `tts` 모드. `audio/voice_ref.wav` 는 `../jei-english-us-strategy/audio/voice_ref.wav`(= `../ai-learning-platform-v3/audio/voice_ref.wav`, D–I 개선 내레이션 29초, 남자 영어 목소리)를 그대로 쓴 것이에요. 속도는 1.0배(`../jei-english-us-strategy` 와 같음)
- `tools/make_audio.py` 는 `../jei-corporation-overview` 판이에요: 문장마다 뒤에 " Thank you." 를 붙여 읽히고 그 앞 쉼에서 잘라, 마지막 음절이 잘리지 않아요. `TAKE` 로 테이크를 고정할 수 있어요

```bash
npm install
N=4 uv run --with numpy --with mlx-whisper python tools/make_audio.py tts   # timeline.js, audio/mix.wav, subtitles.srt
N=8 uv run --with numpy --with mlx-whisper python tools/make_audio.py tts --redo l3_2   # 한 문장만 다시 읽기
```
