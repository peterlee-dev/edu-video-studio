## 음성 · 시각표 만들기

- 대본: `tools/script.py`. JEI 는 모두 "J-E-I", AI 는 "A-I" 로 읽혀요. 숫자는 말로 적었어요(2021 → "twenty twenty-one", 14.6% → "fourteen point six percent", Grades 1 through 4 → "one through four"). 쌍점(:) · 따옴표는 마침표 · 쉼표로 읽혀요
- 목소리: `tts` 모드, 여자 영어 목소리 `audio/voice_ref.wav` = `../adaptive-diagnosis-v2/audio/narration.mp3` 14.1–28.95초(`../jei-repositioning-strategy` 와 같은 목소리). 속도 1.0배
- `tools/make_audio.py` 는 `../jei-repositioning-strategy` 판이에요: 문장마다 뒤에 " Thank you." 를 붙여 읽히고 그 앞 쉼에서 잘라, 마지막 음절이 잘리지 않아요. `TAKE` 로 테이크를 고정해요
- 확인(2026.11.06): 62문장 모두 대본대로 읽혔어요(whisper). l4_2 의 Daekyo → "Dekyo", Woongjin → "Wangjin" 은 받아쓰기 표기 차이일 뿐, 음소(wav2vec2)로 보면 d eɪ k j oʊ · k uː m ɔ n · w ʌ ŋ dʒ ɪ n 으로 바르게 읽혔어요. JEI 는 모두 "dʒ eɪ iː aɪ", AI 는 "eɪ aɪ". 끝인사 Thank you 는 끝이 올라가는 테이크 0 대신 내려가는 테이크 1(339 → 197 → 117 Hz)을 `TAKE` 로 고정

```bash

uv run --with numpy --with mlx-whisper python tools/make_audio.py tts   # timeline.js, audio/mix.wav, subtitles.srt
```
