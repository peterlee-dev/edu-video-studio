## 음성 · 시각표 만들기

- 대본: `tools/script.py` (대본 PDF 와 같고, learning goals → learning objectives 두 곳만 다름). 읽는 문장을 따로 둔 곳: SoR → "S-O-R", CCSS → "C-C-S-S", NAEP(l5_14) → "N-A-E-P", POD → "P-O-D", l6_2 끝에 " ..."(소리 내 읽지 않고 복제 서버가 정하는 길이에 여유를 줘 "U.S." 가 잘리지 않게)
- 목소리: `tts` 모드. `audio/voice_ref.wav` 는 `../adaptive-diagnosis-v2/audio/narration.mp3` 의 14.1–28.7초(그 영상의 복제 문장에 쓴 참조 구간과 같음)를 `make_audio.py ref 14.1 28.7` 로 자른 것이에요. DGX Qwen3-TTS(`http://192.168.51.8:8095`)가 이 목소리를 복제해 문장마다 3번 읽고, whisper 로 받아써 대본대로 읽은 것 중 고르게 읽고 끝이 잘리지 않은 것을 골라요(`audio/tts_cache/`). 복제 서버는 글자 수에 맞춰 길이를 정해서 가끔 마지막 단어 도중에 끊어요: 마지막 50ms 가 말소리 크기 그대로인 테이크는 `cut` 으로 표시하고 고르지 않아요. `cut` 표시가 없어도 끝 무음이 0.1초 아래면 잘렸을 수 있어요: 끝 무음이 0.2초 이상 남은 테이크(서버 길이 안에서 스스로 말을 마친 것)를 골라 `TAKE` 에 고정해요

```bash
npm install
uv run --with numpy --with mlx-whisper python tools/make_audio.py tts   # timeline.js, audio/mix.wav, subtitles.srt
N=8 uv run --with numpy --with mlx-whisper python tools/make_audio.py tts --redo l3_2   # 한 문장만 다시 읽기
```
