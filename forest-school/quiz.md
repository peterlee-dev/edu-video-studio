# 숲 학교 퀴즈·골든벨 정답 모음

## 봄

### 장면 퀴즈

1. 이른 봄에 잎보다 꽃이 먼저 피고, 가지와 잎에서 생강 냄새가 나는 나무는?  
   → **생강나무**
2. 진달래의 다른 이름으로, ‘먹을 수 있는 꽃’이라는 뜻을 가진 이름은?  
   → **참꽃**
3. 민들레 씨를 다 날리고 남은 줄기로 불어서 소리를 내는 것은?  
   → **풀피리**
4. 물에서도 땅에서도 살 수 있는 개구리, 도롱뇽, 두꺼비 같은 동물을 무엇이라고 할까요?  
   → **양서류**
5. 쇠뜨기나 고사리처럼 꽃이 피지 않고 홀씨로 번식하는 식물은?  
   → **양치식물**
6. 모래 속에 개미지옥을 만들어 개미를 잡아먹는 개미귀신은, 무엇의 애벌레일까요?  
   → **명주잠자리**
7. 잣나무는 1년에 몇 마디씩 자랄까요?  
   → **한 마디**
8. 숲 플로깅에서 주운 쓰레기 중, 가장 많았던 쓰레기는?  
   → **비닐**

### 도전! 골든벨

1. 생강나무와 산수유나무 중, 줄기가 매끈한 나무는?  
   → **생강나무**
2. 생강나무는 남자 나무와 여자 나무가 따로 있다. O일까요, X일까요?  
   → **O**
3. 진달래를 부르는 다른 이름은?  
   → **참꽃**
4. 도롱뇽 알은 어떤 모양일까요? 동글동글 덩어리? 길쭉한 튜브?  
   → **길쭉한 튜브 모양**
5. 새는 개구리를, 개구리는 곤충을 먹는 것처럼, 먹고 먹히는 관계를 무엇이라고 할까요?  
   → **먹이 사슬**
6. 쇠뜨기의 생식 줄기로, 끝이 뱀처럼 생긴 것은?  
   → **뱀밥**
7. 대표적인 양치식물로, 어린 싹을 나물로 먹는 식물은?  
   → **고사리**
8. 냉이, 달래, 쑥처럼 봄에 산과 들에서 캐 먹는 나물을 무엇이라고 할까요?  
   → **봄나물**
9. 개미지옥을 만들어 개미를 잡아먹는 명주잠자리 애벌레는?  
   → **개미귀신**
10. 마디가 다섯 개인 잣나무는 몇 살일까요?  
   → **다섯 살**

## 여름

### 장면 퀴즈

1. 무당벌레가 엄청 좋아하는 먹이로, 식물에 붙어 사는 아주 작은 곤충은?  
   → **진딧물**
2. 곤충의 몸은 크게 세 부분으로 나뉘어요. 머리, 가슴, 그리고 나머지 하나는?  
   → **배**
3. 뒷다리를 잡으면 방아를 찧는 것처럼 위아래로 움직이는 곤충은?  
   → **방아깨비**
4. 땅 위로 줄기를 길게 뻗어 자라고, 먹을 수는 있지만 맛이 없는 딸기는?  
   → **뱀딸기**
5. 체온을 스스로 조절하지 못하고, 바깥 온도에 따라 체온이 변하는 동물은?  
   → **변온 동물**
6. 수서 곤충 중에서 가장 크고 힘이 세며, 멸종 위기 야생 생물인 곤충은?  
   → **물장군**
7. 나무껍질을 물에 담그면 물이 파랗게 물드는 나무는?  
   → **물푸레나무**
8. 억새는 산에, 갈대는 강 하구에 살아요. 그럼 계곡에 사는 비슷한 풀은?  
   → **달뿌리풀**

### 도전! 골든벨

1. 무당벌레는 애벌레와 무엇을 거쳐 어른벌레가 될까요?  
   → **번데기**
2. 아무리 더워도 숲에서는 짧은 옷을 입는 게 좋다. O일까요, X일까요?  
   → **X**
3. 곤충의 다리는 모두 몇 개일까요?  
   → **여섯 개**
4. 곤충의 눈 가운데, 크고 많은 눈이 모인 눈은? 겹눈? 홑눈?  
   → **겹눈**
5. 등에 X자 무늬가 있는 메뚜기는? 팥중이? 콩중이?  
   → **팥중이**
6. 다리가 많아서 곤충이 아닌, 절지동물인 친구는?  
   → **노래기**
7. 우리나라 잠자리 중에서 몸집이 가장 큰 잠자리는?  
   → **장수잠자리**
8. 지렁이는 몸의 어디로 숨을 쉴까요?  
   → **피부**
9. 물에 사는 곤충을 무엇이라고 할까요?  
   → **수서 곤충**
10. 다리 끝 잔털 덕분에 물 위를 미끄러지듯 다니는 곤충은?  
   → **소금쟁이**

## 가을

### 장면 퀴즈

1. 꽃이 새처럼 생겨서 이름이 붙었고, 콩처럼 생긴 열매가 열리는 식물은?  
   → **새팥**
2. 버섯은 식물이 아니에요. 곰팡이와 같은 무리인데, 이 무리를 무엇이라고 할까요?  
   → **균류**
3. 물에 띄웠을 때 둥둥 뜨는, 속이 비어 있는 잣을 무엇이라고 할까요?  
   → **쭉정이**
4. 키위랑 비슷하게 생겼고, 키위보다 맛있다는 가을 열매는?  
   → **다래**
5. 손대기만 해도 열매가 톡 터지면서, 씨앗을 멀리 튕겨서 퍼트리는 꽃은?  
   → **물봉선화**
6. 나무가 겨울을 나려고 나뭇잎을 떨어뜨리는데, 이렇게 떨어진 잎을 무엇이라고 할까요?  
   → **낙엽**

   → **참나무**

   → **좀주름찻잔버섯**
4. 큰갓버섯과 닮은 독버섯으로, 가운데에 커다란 비늘 조각이 붙은 버섯은?  
   → **독흰갈대버섯**

   → **청설모**

   → **두충나무**

## 겨울

### 장면 퀴즈

1. 왕사마귀는 어떤 모습으로 겨울을 날까요? 알? 애벌레? 어른벌레?  
   → **알**
2. 생강나무 겨울눈 중에서, 동그란 것은 꽃눈일까요, 잎눈일까요?  
   → **꽃눈**
3. 겨울에 잠깐 깨어나 먹이를 먹고 다시 겨울잠을 자서, 가을에 먹이를 열심히 모아 놓는 동물은?  
   → **다람쥐**
4. 고라니가 겨울에 특히 잘 먹는 것으로, 나무의 영양분이 많이 들어 있는 것은?  
   → **겨울눈**
5. 나무를 쪼아 구멍을 뚫고 애벌레를 잡아먹어서, 많이 살면 건강한 숲이라고 하는 새는?  
   → **딱따구리**
6. 쓰러진 무거운 나무를 들어 올릴 때 이용한, 작은 힘으로 무거운 것을 드는 원리는?  
   → **지렛대의 원리**

### 도전! 골든벨

1. 무당벌레는 어떤 모습으로 겨울을 날까요?  
   → **어른벌레**
2. 호랑나비는 번데기로 겨울을 난다. O일까요, X일까요?  
   → **O**
3. 벌레가 알을 낳으면 나무가 만드는 혹, 벌레혹을 한자로 무엇이라고 할까요?  
   → **충영**
4. 나무가 겨울을 견디며 봄을 준비하는, 가지 끝의 작은 눈은?  
   → **겨울눈**
5. 털옷을 입은 것처럼 보송보송한 겨울눈을 가진 나무는?  
   → **목련**
6. 나뭇잎이 떨어져 나간 자리를 무엇이라고 할까요?  
   → **잎자국**
7. 멧돼지처럼 식물도 먹고 동물도 먹는 동물을 무엇이라고 할까요?  
   → **잡식 동물**
8. 둥지가 크고 접시 모양이면, 주인은 몸집이 큰 새일까요, 작은 새일까요?  
   → **몸집이 큰 새**
9. 새 둥지처럼 보이지만, 다른 나뭇가지에 붙어서 자라는 나무는?  
   → **겨우살이**
10. 딱따구리 둥지에 살기도 하는 천연기념물 동물은?  
   → **하늘다람쥐**
