## 대본 · 음성 · 시각표

- `tools/script.py`: 대본(`SCRIPT`), 장면 목록, 간격. 문장마다 (id, 장면, 쓰는 문장, 읽는 문장, 뒤 쉼)
  - Slide 3의 "이를 위해 AI는 … 비교·분석하고, 이를 바탕으로 … 제안합니다." 한 문장은 두 쪽(p. 5 비교, p. 6 제안)에 걸쳐 있어서 쉼표에서 `l3_2` / `l3_3` 로 나눴어요 (글자는 그대로)
  - 읽는 형태: 영어 이름은 한국어 발음으로(Knowledge Map → 날리지 맵, POD → 피오디, LLM Wiki → 엘엘엠 위키, AI Learning Assistant → 에이아이 러닝 어시스턴트, JEI-SLI → 제이이아이 에스엘아이), 숫자는 말로(50년 → 오십 년, 7개 → 일곱 개, 2026년 4분기 → 이천이십육 년 사 분기). "AI" 와 "1단계 · 2단계" 는 그대로 읽혀요
  - Slide 7의 네 가지 상태 문장은 괄호 안 영어(Mastered 등)를 빼고 읽어요. 영어 이름은 화면의 상태 카드에 있어요
- `tools/make_audio.py tts`: 문장마다 3번 읽혀 whisper large-v3-turbo(mlx-whisper)로 받아쓰고, 대본(쓰는 형태 또는 읽는 형태)대로 읽은 것 중 말 빠르기가 가운데에 가깝고 중간에 긴 쉼이 없는 것을 골라요. 결과는 `audio/tts_cache/` 에 남아서 문장을 고치면 그 줄만 다시 읽어요 (`--redo l3_2,l6_4`)
  - 출력의 `!` 경고 15개는 모두 받아쓰기 표기 차이예요(AI ↔ 에이아이, POD ↔ 피오디, 2단계 ↔ 두 단계, 덧셈 → "더셈", 의 → "에", 4가지 ↔ 네 가지). 대본과 다르게 읽은 문장은 없어요
- 문장 사이 0.45초, 쪽 사이 1.0초(+문장별 쉼). `timeline.js` 에 문장마다 읽힌 단어와 그 시각이 들어가요. 화면은 `Wc(문장, 단어)` 로 그 단어가 읽히는 때에 맞춰 움직여요 — 한국어는 조사가 붙어 읽히므로("효율을", "AI는") 단어의 **앞부분**이 맞으면 찾아요

```bash
npm install
uv run --with numpy --with mlx-whisper python tools/make_audio.py tts   # TTS_URL 기본값 http://192.168.51.8:8095 → timeline.js, audio/mix.wav, subtitles.srt
```
