## 음성 · 시각표 만들기

- 대본: `tools/script.py`. JEI 는 모두 "J-E-I" 로 읽혀요(그냥 두면 "JE" 로 들리는 일이 있었어요, `../jei-english-us-strategy-female`). 연도 · 순위는 말로 적었어요(1977 → "nineteen seventy-seven", 37th → "thirty-seventh", 175th → "one hundred seventy-fifth", Franchise 500 → "five hundred"), eAcademy → "e-Academy"
- 목소리: `tts` 모드, 남자 영어 목소리(ver2). `tools/script.py` 의 `VOICE = 'voice_male'` → `audio/voice_male.wav` = `../ai-learning-platform-v3/audio/voice_ref.wav`(D–I 개선 내레이션, `../jei-english-us-strategy` 와 같은 목소리). 속도는 1.0배(다른 영상과 같음)
  - ver2(4분 47초)는 원래 대본, ver3(4분 37초)은 1차 검토 대본이에요
  - 처음 판(ver1, 4분 25초)은 여자 목소리 `audio/voice_ref.wav`(`../adaptive-diagnosis-v2/audio/narration.mp3` 14.1–28.95초)였어요. 되돌리려면 `VOICE = 'voice_ref'`, `TAKE = {'l6_2': 1}` 로 바꾸고 다시 돌려요(읽은 것은 `audio/tts_cache/` 에 남아 있어 바로 돼요)
- `tools/make_audio.py` 는 `../geo-monitor-ko` 판이에요: 문장마다 뒤에 " Thank you." 를 붙여 읽히고 그 앞 쉼에서 잘라, 마지막 음절이 잘리지 않고 자연스럽게 떨어져요. `TAKE` 로 테이크를 고정할 수 있게 더했어요
- 확인: 고른 테이크 35개 모두 끝에 0.19–0.25초 숨이 있고(끝 소리가 15 dB 넘게 떨어짐), 끝 단어 음소가 끝까지 있어요(`facebook/wav2vec2-lv-60-espeak-cv-ft`). JEI 는 모두 "dʒ eɪ iː aɪ" 로 읽혔는데, `l2_2` 의 처음 고른 테이크만 문장 첫 JEI 가 "jai" 로 들려 `TAKE` 로 고정했어요. 끝의 "Thank you."(`l7_7`)는 세 테이크 중 둘이 "sank you" 로 읽혀 "θæŋk uː" 로 읽힌 테이크로 고정했어요

```bash
npm install
uv run --with numpy --with mlx-whisper python tools/make_audio.py tts   # timeline.js, audio/mix.wav, subtitles.srt
N=8 uv run --with numpy --with mlx-whisper python tools/make_audio.py tts --redo l3_2   # 한 문장만 다시 읽기
```
