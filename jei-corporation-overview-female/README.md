## 음성 · 시각표 만들기

- 대본: `tools/script.py`. JEI 는 모두 "J-E-I" 로 읽혀요. 연도 · 순위는 말로 적었어요(1977 → "nineteen seventy-seven", 37th → "thirty-seventh", 175th → "one hundred seventy-fifth", Franchise 500 → "five hundred"), eAcademy → "e-Academy", R&D → "R and D"
- 목소리: `tts` 모드, 여자 영어 목소리 `audio/voice_ref.wav` = `../adaptive-diagnosis-v2/audio/narration.mp3` 14.1–28.95초(`../jei-english-us-strategy-female`, 남자 목소리 판의 ver1 과 같은 목소리). 속도 1.0배
- `tools/make_audio.py` 는 `../geo-monitor-ko` 판이에요: 문장마다 뒤에 " Thank you." 를 붙여 읽히고 그 앞 쉼에서 잘라, 마지막 음절이 잘리지 않아요. `TAKE` 로 테이크를 고정해요
- 확인: 고른 테이크 42개 모두 음높이가 고르고(문장별 중앙값 195–271 Hz, 2026.11.05에 다시 읽힌 22문장은 200–233 Hz, 2초 창마다 봐도 갑자기 낮아지는 곳 없음), 끝에 0.16–0.25초 숨이 있어요. JEI 는 모두 "dʒ eɪ iː aɪ" 로 읽혔어요(`facebook/wav2vec2-lv-60-espeak-cv-ft`). 끝의 "Thank you."(`l7_7`)는 세 테이크 중 둘이 "tank you"(t eɪ ŋ k)로 읽혀 θ 로 시작하는 0번을 고정했다가, 1차 검토("you 의 끝음이 더 내려가면")로 14테이크를 새로 읽혀 Praat(바닥 75 Hz)로 끝음을 쟀어요. 대부분 "you" 마지막 50 ms 에서 220–250 Hz 로 다시 올라가고, 파일 `_6`(정렬 위치 10)만 164 → 115 Hz 로 내려간 채 끝나요(θ eɪ ŋ k uː, 끝 숨 0.24초). `TAKE` 로 고정했어요. 테이크를 고르는 기준 속도는 원래 모든 테이크의 중앙값이라 한 문장에 테이크를 많이 더하면 다른 문장의 선택이 바뀌어요: `script.py` 의 `PACE = 15.06` 으로 이전 기준을 고정했어요(`make_audio.py` 가 읽어요)

```bash
npm install
uv run --with numpy --with mlx-whisper python tools/make_audio.py tts   # timeline.js, audio/mix.wav, subtitles.srt
N=8 uv run --with numpy --with mlx-whisper python tools/make_audio.py tts --redo l3_2   # 한 문장만 다시 읽기
```
