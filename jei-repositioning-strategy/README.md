## 음성 · 시각표 만들기

- 대본: `tools/script.py`. JEI 는 모두 "J-E-I" 로 읽혀요. 숫자는 말로 적었어요(700 → "seven hundred", 2010 → "twenty ten", 298,000 → "two hundred ninety-eight thousand", 27.5 → "twenty-seven point five", 100% → "one hundred percent"), Al Ries → "Al Reese", 쌍점(:) · 따옴표는 마침표 · 쉼표로 읽혀요
- 목소리: `tts` 모드, 여자 영어 목소리 `audio/voice_ref.wav` = `../adaptive-diagnosis-v2/audio/narration.mp3` 14.1–28.95초(`../jei-positioning-strategy` 와 같은 목소리). 속도 1.0배
- `tools/make_audio.py` 는 `../jei-positioning-strategy` 판이에요: 문장마다 뒤에 " Thank you." 를 붙여 읽히고 그 앞 쉼에서 잘라, 마지막 음절이 잘리지 않아요. `TAKE` 로 테이크를 고정해요
- 확인(2026.11.06): 131문장 모두 대본대로 읽혔어요(whisper; Daekyo → "Dekyo", Woongjin → "Wungjin", Al Ries → "Al Rees", 27.5 trillion won → "$27.5 trillion", 512,000 won → "512,001" 은 받아쓰기 표기 차이일 뿐 음소로 보면 바르게 읽혔어요: d eɪ k j oʊ, w ʊ ŋ dʒ ɪ n, æ l ɹ iː s, … w ʌ n). 음높이가 고르고(문장별 중앙값 189–279 Hz, 높은 쪽은 질문 · 짧은 문장, 2초 창마다 봐도 갑자기 낮아지는 곳 없음), 문장 끝에 0.13초 넘게 숨이 남아요. JEI 는 모두 "dʒ eɪ iː aɪ". 끝인사 Thank you 는 295 → 175 Hz 로 내려가요
