## 음성 · 시각표 만들기

- 대본: `tools/script.py`. JEI 는 모두 "J-E-I" 로 읽혀요. 숫자는 말로 적었어요(1992 → "nineteen ninety-two", June 2026 → "June twenty twenty-six", 53.6 → "fifty-three point six", 130 to 180 dollars → "one hundred thirty to one hundred eighty dollars" 등)
- 목소리: `tts` 모드, 여자 영어 목소리 `audio/voice_ref.wav` = `../jei-corporation-overview-female/audio/voice_ref.wav`(`../adaptive-diagnosis-v2/audio/narration.mp3` 14.1–28.95초). 속도 1.0배
- `tools/make_audio.py` 는 `../jei-corporation-overview-female` 판이에요: 문장마다 뒤에 " Thank you." 를 붙여 읽히고 그 앞 쉼에서 잘라, 마지막 음절이 잘리지 않아요. `TAKE` 로 테이크를 고정해요

```bash
npm install
uv run --with numpy --with mlx-whisper python tools/make_audio.py tts   # timeline.js, audio/mix.wav, subtitles.srt
N=8 uv run --with numpy --with mlx-whisper python tools/make_audio.py tts --redo l3_2   # 한 문장만 다시 읽기
```
